# 중등 수학 70점 돌파 훈련

중1-2, 중2-1, 중2-2 범위를 하루 동안 복습하기 위한 집중형 웹 훈련 자료입니다.

## 구성

- 핵심 훈련 15문항, 권장 35분
- 실전 모의고사 25문항, 제한 120분, 100점
- 공식표, 자동 채점, 오답 다시 풀기
- A4 문제지 PDF 10쪽
- A4 단계별 해설 PDF 16쪽

## 출제 원칙

- 2022 개정 교육과정과 교과서 대표 단원에 맞춰 구성했습니다.
- 공개된 학원 레벨테스트 후기에서 확인된 25문항, 객관식과 주관식 혼합, 약 2시간 형식을 참고했습니다.
- 외부 문제나 그림을 복제하지 않고 모든 문항, 보기, 해설, 도형을 새로 작성했습니다.
- 특정 학원의 공식 문제나 공식 자료가 아닙니다.

## 이용 순서

1. 공식표를 10분 동안 읽습니다.
2. 핵심 15문항을 풉니다.
3. 5분 쉽니다.
4. 실전 25문항을 120분 동안 풉니다.
5. 틀린 문제는 해설의 첫 식을 가리고 한 번만 다시 풉니다.

## 로컬 실행

정적 파일이므로 `index.html`을 열거나 다음 명령으로 실행할 수 있습니다.

```bash
python -m http.server 8765
```

- `index.html`: 단일 파일 웹 앱
- `middle-math-70-exam.pdf`: 문제지
- `middle-math-70-solutions.pdf`: 공식표와 해설지
