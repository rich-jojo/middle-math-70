# v3 고난도 25문항 게시 근거

## 최종 콘텐츠 계약

- 번들: `content/bundles/math70-v3-hard.json`
- 시험 slug: `math70-v3-hard`
- 상태: 문제 25개와 시험 모두 `published`
- 25문항 × 4점 = 100점, 제한시간 7,200초
- 1~18번: 72점 회수 구간, 중1-2·중2-1·중2-2 각 6문항
- 19~25번: 28점 변별 구간
- 전체 학기 분포: 중1-2 7, 중2-1 9, 중2-2 9
- 응답 유형: 객관식 20, 단답형 3, 과정형 2
- 객관식 정답 위치: ①~⑤ 각 4회
- 직접 작성 SVG 7개, 접근 가능한 표 2개
- v2와 본문이 정확히 일치하는 문항 0개

## 초안에서 게시본으로 교정한 사항

1. 1번과 6번을 중2-2 복합 도형 문항으로 교체하여 1~18번 학기 분포를 6·6·6으로 맞췄다.
2. 19번과 21번을 진단성 있는 오답을 가진 객관식으로 바꾸어 20·3·2 형식을 복원했다.
3. 과정형 24·25번에서 최종 숫자만 제출해 만점이 되는 `accepted`/rubric token을 제거했다.
4. `<table>`, `<caption>`, 행·열 머리글을 sanitizer가 보존하도록 테스트와 허용 목록을 추가했다.
5. importer가 중복 보기, 중복 rubric token, 비연속 시험 sequence를 거부하도록 강화했다.
6. 새 설치 시 v2와 v3를 모두 멱등 자동 import하도록 `MM70_AUTO_IMPORT_BUNDLES`를 추가했다.
7. 16번의 범위 밖 중3 곱셈공식 풀이를 중2-2 피타고라스 정리와 넓이 이중 계산 문항으로 교체했다.
8. 12번은 `연립부등식`이라는 선행 오해를 없애고 두 일차부등식의 공통 해로 표현했다.
9. 25번 SVG를 공통 y절편 4와 x절편 2·6의 실제 좌표를 지나도록 다시 그렸다.
10. 과정형 rubric은 주변 부정 표현을 감지하여 `…가 아니다` 같은 거짓 답안에 점수를 주지 않는다.
11. 과정형은 다행 `<textarea>`, 단답형은 한 줄 입력, 객관식은 별도 텍스트 입력 없음으로 UI를 분기했다.

## 난도 해석

v3는 v2보다 단계 수, 조건 결합, 역추론, 경계 처리, 경우 누락 방지와 증명 요구를 늘린 설계상 고난도 시험이다. 다만 실제 정답률·풀이 시간에 근거한 경험 난도는 아직 없으므로, 첫 실응시 후 64~80점 구간의 오답률과 소요 시간을 보고 레벨을 보정한다.

v2와 `body_html`이 정확히 같은 문항은 없지만, 같은 교육과정 단원에서 순환소수·도수표·닮음·일차함수·합동 증명 같은 대표 풀이 유형은 일부 반복된다. 따라서 “문항 본문과 수치·조건은 신규”라고 말할 수 있으나 “25개 풀이 구조가 전부 v2와 무관하다”고 과장하지 않는다. 반복 유형도 조건 결합이나 후속 판단 단계를 추가해 v2보다 어렵게 설계했다.
